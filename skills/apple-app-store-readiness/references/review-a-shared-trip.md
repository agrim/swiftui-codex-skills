# A reviewer opens an invitation to a shared trip

Build the review notes around what the recipient can actually do. Supply a working sample invitation or explain how the reviewer can issue one. A recipient who follows the link should see the intended trip or a useful sign-in step and return to that trip afterward. If the service never received the invitation, fix the sending or delivery path. Adding a manual importer to the recipient’s screen hides the failure.

Use Xcode Organizer to identify the Release archive and App Store Connect to select its processed version and build. On a clean TestFlight installation, follow the public HTTPS link from outside the app. If the website opens unexpectedly, inspect the installed associated-domains entitlement, the domain’s association file and the route handler. A local simulator fixture cannot establish the public domain association.

Check that the support page provides help, the policy describes the data the app actually sends, and any required service or demo access will remain available during review. Capture storefront images from coherent states in the candidate. For a new icon, follow the canonical editable asset through the archive to the Home Screen, including a small size and the supported appearance variants. Keep credentials in the designated review channel.
