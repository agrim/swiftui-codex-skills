# Finding the first broken step in an accessible journey

A release moves Save into a toolbar on the trip editor. Start at the list, open the editor, change a name, save it, then locate the updated trip. A screenshot of each screen can look correct even if focus disappears as the sheet closes.

On the installed candidate, run the journey with the input method the change affects. Record where focus lands after dismissal and what the next normal action does. If the sheet closed but the person cannot get back to their trip, record that first broken transition along with the starting state and destination.

For a change that touches many screens, group them by the interaction they share. Inspect a representative of each group, then expand a group when you find a difference. Keep an explicit record of unvisited variants so a partial review can be resumed without claiming broader coverage.
