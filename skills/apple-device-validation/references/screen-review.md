# Save moved into a toolbar. Can someone still finish?

On the installed candidate, open an existing trip, rename it, activate Save using VoiceOver or the hardware keyboard, then locate the edited trip. Record the first action that breaks. A correctly rendered sheet can still strand focus after dismissal.

For a review spanning several screens, distinguish the state from its capture. Record the build, fixture, appearance, text size and capture ID. If two different states point to the same image, confirm what was actually captured. A design mockup can show intent. Only a runtime capture shows how that build rendered, and only an interaction settles where focus landed.

Keep feedback attached to the capture it describes. When a new capture replaces one already accepted, carry forward the issue and check it again. Group shared controls for a first pass, but record missing states and unvisited variants. Mark the journey complete once the required states and transitions have actually been observed.
