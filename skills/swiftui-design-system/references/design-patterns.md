# Reviewing a component across surfaces

## The same record looks like a different entity

Compare the picker, library and history using the same record and state. Align typography, information order and spacing where they express the same meaning. Keep selecting a template, editing it and viewing a confirmed record as distinct commands. Factor out the shared presentation once those boundaries are visible.

If primary and destructive actions compete visually, compare the next intended action and the cost of an accidental activation. A tool palette may legitimately have several peers. Identify the cue that distinguishes the primary action after the longest label wraps.

## A theme makes a label disappear

Render the same disabled, selected and destructive controls in light, dark and increased contrast. Remove the custom foreground first. If only one foreground/background pair fails, fix the shared role at its definition. If the issue follows one component across themes, inspect that component's inherited style. Filter and reorder colored records to detect a palette indexed by display position. Check persisted theme selection on relaunch only if the app offers themes.

## The fallback icon changes the meaning

On the minimum target, activate the control with its fallback symbol and full localized label. If the symbol competes with the label in a compact presentation, remove the redundant decoration and repeat at large text. Compare pressed and focused states against the actual background.
