# Choose a build experiment

Identify which wait matters. A developer blocked after editing one file and a CI worker on a fresh machine have different workloads. Record a representative stimulus and the elapsed baseline before proposing a change. For a benchmark-only request, leave the project untouched.

Follow the timeline to the dependency that determines completion. A large aggregate compile total can consist of overlapping tasks. Classify the observed delay as project-owned, toolchain, environment or unresolved. Only propose a project change if its owner and expected effect can be demonstrated.

State what would falsify the hypothesis, including a correctness or compatibility regression. An estimated saving stays an estimate until the original workload is rerun.
