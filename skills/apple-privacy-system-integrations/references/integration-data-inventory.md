# Trace a record through deletion

Choose a synthetic record with a recognizable value. Follow it through local storage, a cloud container, linked SDKs, derived summaries, extension caches, logs, and support exports wherever the feature uses them.

| For each copy, identify | Evidence to collect |
| --- | --- |
| Purpose, operator, and access | Which component writes it, where it lives, and who can read it |
| Retention and removal | Deletion trigger, owner, propagation delay, and any user-controlled export the app cannot retract |
| Disclosure | Whether the signed archive, public statement, and observed data flow agree about this use |

Delete the record, switch accounts, and reopen the widget, index, and diagnostics that received it. Look for the synthetic value after each transition. Inspect a queued response arriving after logout so it cannot repopulate a cleared cache. A product with no developer-operated backend can still leave identifiable records in cloud storage and support logs.
