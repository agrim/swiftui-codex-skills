# Should “Move note” finish in Shortcuts?

“File my packing list in Travel” can finish outside the app if the person can identify the note and folder. If filing requires comparing note contents, open the collection at that choice. For the shortcut, resolve both inputs and call the same move operation as the app menu.

Save the shortcut in a personal account. Switch to a work account that also has a folder called Travel. Resolve the saved identifiers against the current account and permissions. Looking up the name and choosing the first match could move a work note or reveal a private title. When access is gone, offer a new selection with a neutral prompt.

Run it with the app closed. Cancel the folder prompt and verify the note stays put. Complete it and reopen the note in Travel. If moving it also sends an alert or adds an audit entry, a lost reply needs reconciliation before retrying. Finding the note in Travel alone cannot tell you whether that side effect ran twice.
