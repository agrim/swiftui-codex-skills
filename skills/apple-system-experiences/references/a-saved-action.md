# Should “Move note” run in Shortcuts or open the app?

“File my packing list in Travel” is a good shortcut when the person can identify both the note and the folder. Run the same move that the app offers in its menu. If the choice depends on reading several notes side by side, open the relevant collection and let the person decide there.

A saved shortcut can outlive its inputs. Imagine the owner switches from a personal account to a work account that also has a folder named Travel. Resolve the saved note and folder by their identity in the current account. Matching the name and picking the first result could move a different note. Offer a fresh choice when the original is unavailable. Keep private titles out of that prompt.

A cold invocation should be able to use the operation without constructing a window. If the user cancels the folder prompt, leave the note in place. If the move was submitted and its reply was lost, inspect the recorded outcome before offering a retry. The result someone sees in Shortcuts should agree with the folder they open later.
