# Changelog

## 2.0.0 — Portable skill-library redesign

Carries forward the existing strengthened seven-skill branch rather than reverting to the older six-skill main branch. Preserves all existing published skill identifiers and optional adapter files.

Adds focused state, concurrency, navigation, layout, controls, accessibility, design, persistence, networking, testing, platform, interop, and system-experience modules. Rewrites the existing entry points and playbooks around explicit inputs, stable rule IDs, workflow, evidence, and output contracts.

Replaces universal foreground/interop prohibitions with scoped semantic and lifecycle rules. Separates platform facts from engineering recommendations and unverified claims. Introduces a provider-neutral catalog, source-review registry, coverage limits, progressive loading, safe explicit-directory installation, and portable bundles.

Replaces mandatory vendor metadata validation and blanket scanner failures with portable contract checks and severity-based advisory triage. Adds regression tests, Swift examples, CI, source-linked maintenance guidance, and behavioral evaluation contracts. Mechanical tests are not presented as cross-model or real-device validation.

No repository rename, license selection, App Store action, or automatic public release is part of this change.
