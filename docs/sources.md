## Refresh policy

Before using a version-sensitive API or a release/privacy requirement, inspect the current official page and installed SDK. Re-review affected sources on relevant SDK/HIG releases or reported contradictions. Update dates only after inspecting content and recording any resulting changes. Prefer the precise symbol/article over a framework landing page. Never infer API availability from a source review date.
