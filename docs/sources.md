## Scoped review notes

`accessibility-input-labels`: Localized alternatives and their priority for voice input.

`activity-stale-date`: Reaching the stale date changes activity state to stale. The case distinguishes that from ending the trip.

`any-layout`: Switching layout types while preserving the state of the same subviews.

`api-design`: Naming at call sites, side effects, complexity, defaults, and documentation; not a review of every standard-library API.

`build-script-inputs`: Run Script inputs and outputs determine scheduling and rebuilds. File lists handle varying sets.

`build-speed`: Read the official documentation JSON: timing summaries, accurate dependencies, script input/output declarations, module reuse, and measured target refactoring.

`color`: Color meaning, custom appearance and increased-contrast variants, and semantic system colors; inspected official documentation content for the repeated-surface and theme guidance.

`coredata-batch`: Store-level deletion and merging deleted object IDs into registered contexts; archived conceptual guidance, not current API availability proof.

`coredata-confinement`: Queue confinement, perform-based access, and managed object ID transfer. Archived conceptual guidance; compile current APIs against the installed SDK.

`coredata-context-save`: A child save updates its parent. Writing to the external store requires saving the entire chain.

`coredata-existing-object`: The throwing lookup returns a registered object or fetches from the store; it throws if both lack the ID.

`coredata-permanent-ids`: Obtaining a permanent ID leaves the object inserted until it is saved.

`distribution-build-number`: Xcode distribution settings can update the build number of the archive content during distribution. The uploaded number identifies the candidate in App Store Connect.

`file-protection-complete`: A completely protected file cannot be read or written while the device is locked or booting.

`focus`: The same focus value can identify two views ambiguously. Programmatic focus then chooses the first candidate and emits a runtime warning.

`health-authorization`: Authorization status concerns saving the specified type. HealthKit deliberately does not disclose read authorization to the app.

`identifiable`: The type defines the scope and duration for which an ID identifies the same entity.

`imageio-thumbnail-pixel-limit`: The Image I/O thumbnail maximum bounds width and height in pixels.

`instrument-hang-thread-states`: Time Profiler samples running code, while Thread State Trace identifies the stack that initiated a wait in the selected hang interval.

`intent-needs-value`: Throwing needsValueError requests a value and re-performs the intent with that value.

`keychain-item-accessibility`: The default accessibility permits reads when unlocked. Select an accessibility class that fits the item’s sensitivity and intended access.

`list-performance`: Row identity gathering, conditional row counts, and the cost of inline filtering.

`localized-standard-search`: Standard localized substring search is locale-aware and case- and diacritic-insensitive.

`model-data`: Views form dependencies on accessed observable properties, including those read via computed properties. Intermediate views may pass models through without acquiring these dependencies.

`navigation`: Value-based navigation paths and the removal of direct-view destinations above them when pushing a value.

`notarize-containers`: ZIPs can be submitted, but ticket stapling is applied to the contained item before creating a new ZIP; disk images and flat installer packages can be stapled directly.

`nshostingview-root`: NSHostingView exposes a mutable rootView property isolated to the main actor.

`privacy-tracking-domains`: If tracking permission is absent, network requests to declared tracking domains fail. The entries identify domains the app or SDK uses for tracking.

`security-interaction-not-allowed`: This status means interaction with the Security Server is disallowed; the code alone does not establish a missing credential.

`stream-buffering`: Retention of oldest or newest pending elements at capacity.

`stream-termination`: Cancellation of active iteration and termination callback behavior.

`stream-yield`: Immediate return and results for enqueued, dropped, or terminated delivery.

`swift-task-lifetime`: Completion releases a task closure and its captures; dropping the task handle does not stop the work.

`swift-testing-arguments`: Two argument collections form all combinations. One collection of paired cases instead invokes the body once for each supplied pair.

`swift-zip-pairs`: Pairing sequences of unequal length silently limits the result to the shorter sequence.

`swiftdata-fetch-limit`: The fetch limit caps the models returned by that fetch.

`swiftdata-migration`: Ordered schemas and migration stages used when opening a versioned store.

`swiftdata-rollback`: Rollback discards pending inserts and deletes and restores changed models to their last committed state across that context.

`swiftdata-schema-stages`: Versioned schemas, lightweight attribute renames, and resolving duplicates before enforcing uniqueness.

`swiftdata-transient-property`: Transient properties are omitted from persistent storage. SwiftData also treats computed properties as transient.

`swiftui-accessibility-representation`: A nonvisual representation replaces default accessibility elements. A custom style on a native control can inherit accessibility behavior.

`swiftui-active-search-scope`: The binding selects the active scope of the search field.

`swiftui-chart-descriptors`: A representable supplies an AXChartDescriptor. Implement updateChartDescriptor to update its existing representation when relevant environment values change.

`swiftui-dismiss-action`: Dismiss acts in the environment where it was read. Reading it in the presenting window root can close that window on macOS or iPadOS.

`swiftui-instruments`: Selecting an update interval, inspecting CPU samples, and tracing frequent updates to dependencies.

`swiftui-onchange-perform`: The legacy closure receives the new value. The previous value can be captured in that closure.

`swiftui-onchange-values`: The two-value action receives both old and new values. initial defaults to false, and captures come from the updated closure.

`swiftui-open-window`: For WindowGroup, opening by group ID alone creates a new window. Opening by group and value brings a matching presented value forward, or creates one when absent.

`swiftui-state-object`: An external input can seed the object once per view identity. SwiftUI evaluates the autoclosure only on initial creation, and changing identity resets other local state.

`swiftui-trigger-task-id`: When the ID changes, SwiftUI cancels the previous task and restarts it.

`swiftui-vertical-safe-area-inset`: A vertical safe-area inset makes space in the modified view for content anchored to the specified edge using its height.

`swiftui-view-id`: Changing the bound identifier resets view identity, including state.

`testflight-external-groups`: Internal Only builds cannot join external groups. Automatic and manual notification differ.

`testflight-storekit-sandbox`: In-app purchases in TestFlight builds use the StoreKit sandbox. A successful beta purchase cannot establish production product availability.

`testing-async-events`: A confirmation checks its count at the end of the supplied closure.

`understanding-hangs`: The main run loop normally sleeps between events. A lengthy period handling work can prevent timely processing of incoming events.

`urlsession-task-cancel`: A cancel request returns immediately and delegate messages can still arrive.

`view-that-fits`: Candidate order, ideal size, and fitting along the specified axes.

`voice-control-criteria`: Interaction by visible name, overlays, dictation, and navigation to controls.

`watch-context-replacement`: A later application context replaces the preceding dictionary. Delivery is opportunistic, including while the counterpart is unreachable.

`widget-refresh`: WidgetKit supports entries for predictable future dates and timeline reloads for changed data; actual presentation time can vary.

`xcconfig-settings`: Xcode layers project/target/configuration settings. $(inherited) augments a setting.

`xctestrun-products`: build-for-testing produces .xctestrun. test-without-building with -xctestrun resolves test bundles at paths identified by the file.

`xcui-hittable`: An existing offscreen or covered element can be unhittable, including a row reachable by scrolling.


## Refresh policy

Before using a version-sensitive API or a release/privacy requirement, inspect the current official page and installed SDK. Re-review affected sources on relevant SDK/HIG releases or reported contradictions. Update dates only after inspecting content and recording any resulting changes. Prefer the precise symbol/article over a framework landing page. Never infer API availability from a source review date.
